# Design references and provenance

This package is original workflow prose and helper code under the included MIT license. No source code was copied from the repositories below. The user's complete V3.1 output specification is included as the reusable writing contract. It replaces the earlier sample-derived superscript/Works cited and audit-chapter formatting. The four earlier DOCX examples and their scientific content are not included.

- V2 PhD Deep Research Agent: high-recall question decomposition, query families, source/route recording, literature map, anchor audit, separate retrieval/concept saturation. V3 retains those capabilities while changing the automatic phase transition and public web evidence boundary.
- LangChain Open Deep Research: https://github.com/langchain-ai/open_deep_research — configurable research orchestration and source retention. This package does not copy its prompts or source.
- GPT Researcher: https://github.com/assafelovic/gpt-researcher — question decomposition, source tracking, report workflow.
- Scholarly Deep Research: https://github.com/Tw6249/scholarly-deep-research — normalized paper records, citation neighborhood, query logs. Its API connector, gated search, and PDF parsing are intentionally excluded.
- PaperQA2: https://github.com/Future-House/paper-qa — question-centered evidence attribution. Its local full-text/PDF pipeline is not a dependency.

A high-count search does not prove high recall; a citation path can be incomplete when public pages omit references. The workflow must record that incompleteness honestly. The final report should quantify the executed process and source tiers, not estimate the unknown total population of relevant papers.
